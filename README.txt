TEXLearn ASCEND starter package

Copy:
- ascend.html to repository root
- css/ascend.css to css/
- js/ascend-modules.js to js/
- js/ascend.js to js/

This starter reuses the existing root js/config.js and the existing localStorage
Gamification token + Library customer identity. It does not create a second login.

The module registry is currently local/configuration-driven. A future admin API
can provide the same module data dynamically. Challenges, Quiz Arena and
Leaderboards are not yet fully implemented workflows; they are expandable
navigation modules. The hero avatar is a CSS placeholder until final 3D assets
are approved.
